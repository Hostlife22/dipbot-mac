# DipBot Mac: выпуск улучшений 25.09.2026

Изменения реализованы в приложении, проверены по этапам и отправлены в master.
Подробности и воспроизводимые доказательства: [план и результаты](IMPROVEMENT_ROADMAP_RU.md).
Сборка: [платформа, зависимости, SHA-256](improvements/release-build.json).

## Проверки выпуска

613 offline тестов прошли; после двух правок компоновки — ещё 32 целевых Qt-теста.
Сборка Intel, `codesign --verify --deep --strict` и smoke финального `.app` прошли.
Реальный Qt восстановил новые политики после закрытия и повторного открытия;
при 940×700 раскрытые настройки не создают горизонтальный скролл.

[10 минут PAPER через `.app`](improvements/paper-release-10m.json): 7361 проверка
интерфейса, 118 разных цен, ошибок и расхождений 0. Ручной BUY/SELL, STOP/START,
20-секундный обрыв RPC и синтетическое восстановление minOut прошли. Естественного
автоматического входа в этом интервале не было; он не доказывает полный рыночный
цикл DIP→BUY→TP/SL→SELL. Ранее автоматические входы/выходы наблюдались в
[15-минутном прогоне](improvements/paper-modern-15m.json), на более ранней версии.

Рыночный прогон относится к коду `ee5f8f6`. Финальная сборка `5d96bae` отличается
только переносом строк формы и минимальной шириной полей; эти изменения проверены
отдельно. Торговый код идентичен. Это отражено в manifest, а не выдано за повторный
рыночный прогон новой упаковки. [Снимок остановленного PAPER](improvements/paper-release-stopped.png).

## Что изменилось

- Цена: кеш только в пределах того же канонического блока, V3 Multicall,
  необязательный WSS, адаптивный read RPC, отдельное наблюдение при исполнении.
- Вход: оконный/волатильностный DIP и отскок как отдельные режимы, фильтр Swap,
  проверка BUY→SELL на сумму, сравнение маршрутов, USD-размер и резерв газа.
- Выход: TP/SL по котировке, trailing, срок удержания, cooldown; STOP до подписи
  входа и отдельная ручная отмена pending тем же nonce.
- Учёт: исторический USD, газ, закрытие через Sweep, неполные данные без
  выдуманной прибыли, прочие расходы без двойного вычитания. Footer только USD.
- Проверка: модель задержки/расходов PAPER, записи, причинный replay, holdout,
  local-fork сделки, fault-тесты и контроль интерфейса.

Экспериментальные режимы и необязательные фильтры не включаются автоматически.
Обязательного накопительного ограничения оборота нет. Старый legacy DIP сохранён.

## Запуск

Проверенная локальная сборка находится в репозитории:

```bash
open 'dist/2026-09-25-r2/DipBot Mac.app'
```

Обычная пересборка из исходников:

```bash
uv sync --frozen --group dev
uv run --frozen pytest -q
./BUILD_MAC.command
```

`BUILD_MAC.command` создаёт `dist/DipBot Mac.app`. Установка поверх другого
открытого экземпляра не требуется. Новые экземпляры обычного приложения
ограничены существующей блокировкой запуска.

## Настройка

1. Укажите основной HTTP RPC. Backup, WSS и RPC отправки необязательны.
   Отдельный RPC отправки проверяется на chainId 56; public fallback для него нет.
2. Через AutoPair найдите пулы. «Сравнить на AMOUNT» сравнивает одну TARGET/BASE
   пару на одном блоке; выбор маршрута остаётся явным.
3. Для USD-размера дождитесь свежего USD-курса базы. Газ не входит в AMOUNT.
4. Для PAPER задайте задержку и стоимость операции в базе пары. Default 0.25 с
   и 0 расходов — допущение модели; реальный token tax автоматически не известен.
5. Экспериментальные режимы проверяйте отдельно. Короткая удачная серия не
   является основанием автоматически менять параметры LIVE.

## Незавершённая операция

Сначала проверьте receipts и сохранённые позиции. «Отменить pending…» —
отдельная реальная транзакция с показанной комиссией; исходная сделка может
подтвердиться первой. После отмены торговля остаётся заблокированной.
Снятие блокировки очищает кэш позиций, но не продаёт остатки кошелька.

STOP не отменяет уже отправленную транзакцию. Он запрещает новые входы,
дожидается результата текущей операции и закрывает отслеживаемую позицию,
когда результат достоверен. Неизвестный результат требует сверки.

## Обновление и откат

Формат preferences остаётся version 1 с необязательными полями. Старые настройки
получают defaults, неизвестная себестоимость/FX не восстанавливается догадкой.
Перед откатом версии завершите операции, проверьте балансы и сохраните локальную
копию `~/Library/Application Support/DipBotMac/state.json` вне Git. Keychain
отдельный: копия state.json не содержит резервной копии ключа.

Не заменяйте текущий журнал старой копией после реальных транзакций: это может
скрыть использованный nonce и изменить учёт. При незавершённой операции сначала
используйте актуальную версию для сверки. Старые версии не понимают всех новых
состояний отмены и распределения расходов.

## Границы результата

- Протестирован Intel Mac; ARM и notarization не подтверждены. Подпись ad-hoc.
- В этом цикле улучшений mainnet-транзакции не отправлялись. Local-fork и
  локальный mempool используют синтетические средства и не доказывают LIVE.
- Приватность RPC, MEV и сроки включения зависят от провайдера; клиент их не гарантирует.
- PAPER/replay не воспроизводят произвольные налоги, blacklist, MEV и поведение
  владельца токена. Fork — проверка конкретного состояния, не будущая гарантия продажи.
- Причина прежнего необъяснённого завершения не установлена: новые прогоны его
  не воспроизвели. Добавлены crash-marker, стеки и периодические checkpoint.
- Доходность и превосходство над другими ботами не доказаны. Holdout пока
  не дал достаточно независимых закрытий для выбора победителя.
- USD P&L относится к отслеживаемым закрытиям. Отдельная сводка вычитает прочий
  записанный газ; это не NAV всего кошелька и не переоценка внешних переводов.
