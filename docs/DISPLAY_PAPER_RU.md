# Проверка отображения PAPER в окне macOS

Проверка использует видимый Cocoa-интерфейс и временное хранилище.
Keychain и отправка транзакций заблокированы. Реальных сделок нет.

## Подтверждённые проблемы до исправления

- После PAPER → DEMO оставались 180 точек графика предыдущего рынка.
- У графика не было шкалы времени, ценовых подписей и уровней стратегии.
- При постоянной очень маленькой цене линия рисовалась у нижнего края.
- Кнопка START выглядела активной при RUNNING, хотя была disabled:
  стиль primary перекрывал общий disabled-стиль.
- Не было возраста котировки и явной подписи единицы цены.

[Вид до исправления](DISPLAY_BEFORE.png): живой PAPER на PeaceBear, без покупки.

## Исправления

- Очистка графика, цены и уровней при смене рынка/режима/источника цен.
  При неподтверждённом рынке запоздалое событие цены не восстанавливает график.
- Источник котировки передаётся Worker: DEMO, BSC либо явно помеченный REPLAY.
- Подпись: **1 TARGET в базовом активе**; например WBNB, не USD.
  «КОЛИЧЕСТВО TARGET» показывает число токенов в позиции, не цену цели.
  Полные значения цены и количества доступны в tooltip; краткий вид — 8 значащих цифр.
- Уровни вычисляются по активным Settings в Worker: DIP = base × (1−dip/100),
  TP/SL = entry × (1±порог/100). При открытой позиции показаны ENTRY/TP/SL,
  без позиции — DIP; после остановки без позиции уровни скрыты.
- Цветные линии и легенда уровней, ценовая шкала и временная шкала по времени
  получения событий в GUI. График содержит последние 180 чтений, не свечи.
  Промежутки более 0.55 с не соединяются линией; отрицательная цена на оси не рисуется.
- Возраст последней котировки и сообщение о разрыве при RUNNING.
- START при RUNNING явно серый; очистка цены не выдаёт прошлый рынок за текущий.

## Как проверялось

1. Открыто видимое окно, подключён read-only RPC, выбран проверенный V2 USDT/WBNB.
   Нажаты CHECK POOL и START, выполнен PAPER на настоящих котировках.
2. После каждого price сверены текст цены и последняя точка графика; после status —
   количество TARGET, активные линии и блокировка START.
3. Выполнены STOP и переключение режима: старая цена и график должны исчезнуть.
4. В том же интерфейсе воспроизведены сохранённые цены PeaceBear из предыдущего
   рыночного теста. Большая надпись и подпись источника указывают **повтор записи**.
   Это проверка отображения переходов BUY/TP/SL; не новый рыночный прогон.
   Порядок отсчётов сохранён, интервал повторения 0.1 с, исходное время не воспроизводится.
5. После SL проверены нулевая позиция, остановка, очистка при смене рынка и закрытие.

Исходная версия: 45 с живого рынка, 1548 сверок, 0 расхождений;
повтор записи — 4 BUY, 3 TP, 1 SL. [Результат](DISPLAY_SOURCE_CHECK.json).
После этого визуально разведены подписи линий в легенду и отделён источник REPLAY.
Полный offline-набор — 368 passed; после финальной правки — 16 целевых тестов passed.

## Запуск проверки

```sh
'dist/DipBot Mac.app/Contents/MacOS/DipBot Mac' \
  --display-check /tmp/dipbot-display-new \
  --display-replay docs/VOLATILE_PEACEBEAR.json \
  --acceptance-seconds 60
```

Каталог должен быть новым. Тестовый режим не использует пользовательское
хранилище или кошелёк. Успех интерфейсной проверки не доказывает доходность
стратегии либо исполнение реальных сделок.
