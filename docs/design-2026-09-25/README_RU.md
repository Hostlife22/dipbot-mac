# Дизайн DipBot Mac — 25.09.2026

## Результат

Обновлён настоящий интерфейс PySide6, без смены Qt-стека и торговых правил.
Общие цвета вынесены в семантические токены; уменьшены заголовки, отступы и
показатели. AutoPair и дополнительные настройки стратегии раскрываются отдельно.
Выбранные TARGET, база, версия маршрута и пул видны в краткой строке;
полные адреса доступны в подсказке и полях. Режим имеет постоянную текстовую метку,
LIVE дополнительно выделен предупреждением.

На графике различаются текущая цена, база DIP и порог входа. После покупки
показываются переданные стратегией уровни ENTRY/TP/SL/TRAIL; подписи разводятся,
а разрывы наблюдений не соединяются линией. ENTRY («Вход*») — опорная цена
стратегии, не средневзвешенная цена исполнения. Изменение относительно неё
помечено как изменение цены, не прибыль позиции. USD остаётся справочным курсом.

Состояния поиска, PENDING, ожидания DIP, открытой позиции, исполнения,
устаревшей цены, ошибки RPC, STOP и неопределённой LIVE-операции имеют
текстовое объяснение и визуальное выделение. Ошибка остаётся видимой после
обновления нижнего P&L. Нижний P&L — только закрытый результат в USD, 12 px.
Поля связаны с подписями для доступности; сохранены подтверждения реальных действий.

## Проверки

- 622 offline pytest-теста прошли, включая 9 новых UI-регрессий.
- Нативный Qt/Cocoa: 26 снимков, четыре размера окна, геометрия графика/статуса,
  доступность footer/STOP, отсутствие горизонтальной прокрутки, Tab и перезапуск
  настроек. [Отчёт](report.json).
- Реальный Worker с искусственным рынком: автоматический DIP→BUY→TP,
  обрыв RPC с позицией и SL после восстановления, STOP, ошибка продажи и ручной
  повтор. [Отчёт](worker-scenarios.json).
- Новый процесс: восстановление настроек, позиции, pending-блокировки, сверка
  receipts и несовпадения балансов без снятия блокировки. [Отчёт](worker-restart.json).
- Те же сценарии исполнения проверены через собранную `.app`:
  [отчёт](bundle-scenarios.json), [перезапуск сборки](bundle-restart.json).
- Smoke исходников и `.app`, `codesign --verify --deep --strict` прошли.
  [Путь сборки и SHA-256](build.json).

Старый сценарий `position_check` ожидал устаревшую строку «USD недоступен».
Он обновлён: проверяется отсутствие долларового результата и сообщение о
неполном USD-учёте при отсутствии FX. Расчёт P&L не изменён.

Воспроизведение:

```bash
uv run --frozen pytest -q
uv run --frozen python -m tools.design_audit --output /tmp/dipbot-ui-audit
QT_QPA_PLATFORM=offscreen uv run --frozen python launcher.py --smoke-test
./BUILD_MAC.command
codesign --verify --deep --strict 'dist/DipBot Mac.app'
```

## Границы

Mainnet-сделок не было, Keychain и пользовательские ключи не использовались.
Проверки LIVE касаются интерфейса и искусственных сценариев восстановления.
В раскрытых настройках и длинных журналах используется вертикальная прокрутка;
нижние действия и закрытый P&L остаются вне неё. VoiceOver целиком и системное
масштабирование шрифтов отдельно не проверялись. Сборка Intel, подпись ad-hoc;
notarization и нативная Apple Silicon-сборка в этот этап не входили.
