# AutoPair, ADD, Sweep и настройки: второй статический проход

Дата: 2026-09-24. База: `74ca2a9`. Этот отчёт уточняет предыдущие `AUTOPAIR_PARITY_RU.md` и `STATIC_RECOVERY_AUDIT_RU.md`. Это реконструкция поведения, не восстановленные Python-исходники. Windows EXE не запускался; реальные RPC, транзакции, пользовательские настройки, лицензия и Keychain не использовались.

## Новые свидетельства

Исследован ранее не разобранный модуль `commercial_features`: 642 константы, включая большие целые Nuitka. Добавлен декодер g/G (31-битные разряды, старший первым). Проверены машинные инструкции и псевдокод r2/r2ghidra; имена функций сопоставлены с телами, а не только с соседними строками.

[WORKFLOW_EVIDENCE.json](WORKFLOW_EVIDENCE.json) содержит SHA256 релиза, адреса таблиц, выбранные публичные константы и хеши 16 диапазонов. Воспроизведение:

```bash
uv run --frozen python -m tools.workflow_native /path/to/original.exe --output /tmp/workflow.json
# Для --disassembly /tmp/workflow-asm требуется отдельное окружение с capstone.
```

Неподходящий SHA256 отклоняется. Утилита читает EXE как данные. Бинарник, полный дамп констант и пользовательские файлы в репозиторий не включаются.

## AutoPair

- Добавлен resolver адреса ERC-20, канонического V2/V3 пула и базы каталога. Для базы возвращается `CATALOG_TOKEN`; автоматическое открытие/добавление профиля по этому событию пока не перенесено.
- Поиск factory и чтение сторон/ликвидности объединены в `aggregate3` Multicall. Пакеты привязаны к одному блоку; выбранный пул заново проверяется перед использованием. Decimals и финальная проверка читаются отдельно. Ошибка декодирования прерывает поиск; не подменяется нулевой ликвидностью.
- Добавлена задержка ввода **220 мс**, защита от результатов предыдущего ввода, STOP и изменения router/пары. Устаревший результат не выбирает пул.
- **Исправление прежнего вывода:** наличие автоматического периодического опроса PENDING в оригинале не доказано. `CommercialGUI.__init__` задаёт `setSingleShot(True)` и 220 мс; `_schedule_autopair` останавливает/запускает таймер ввода; проверенная PENDING-ветка `_handle_autopair_result` его не перезапускает. Mac повторяет поиск при новом вводе или нажатии AutoPair. Сам PENDING не разрешает торговлю.

Свидетельства: `0x1408f5f80–0x1408f9c4a`, `0x1409093b0–0x140909f9f`, `0x14090cac0–0x14090fd85`. Совпадение таймингов RPC и всех ошибок resolver в работающем Windows не проверено.

## ADD/REMOVE профилей

Восстановлен `_probe_live_pair_converter`, `0x1408ff890–0x140900e81`:

- Sample — **10^15 wei = 0.001 BNB**, `commercial_features[508]`; прежние Mac 0.01 BNB/10% заменены.
- Preview slippage — **3%**, `[206]`; это параметр minOut, а не допустимая потеря round trip. Проверка котировки Mac использует точный предел **15%** из конвертера. Оригинал округляет loss до целых bps: на границе остаётся небольшое намеренное отличие.
- Неизвестная база начинает с `via_usdt_v3`, fee 500 (`_converter_seed_profile`, `0x1408fed60–0x1408ff888`). При невозможности маршрута проверяется `via_eth_v3`. Mac не маскирует RPC timeout таким переключением, тогда как оригинальная ветка ловит Exception.
- BUY и обратная котировка используют один фактический маршрут. Сохранённые mode/fee применяются отдельно для router; ADD повторно проверяет торговый пул.
- Имена используют очищенный uppercase symbol, до 16 символов, с адресным суффиксом и номером при коллизии. Свидетельства: `safe_symbol` `0x140bac2d0–0x140bacbe8`, `_unique_name` `0x140bbbcd0–0x140bbe272`. Mac сохраняет прежние имена и глобальную уникальность alias; оригинальная область имён по router отличается.

REMOVE сохраняет существующие проверки остатков/позиций, удаляет только выбранную router-запись и обновляет каталог. Полная последовательность Windows UI, проверки всех его конвертеров, V2 tax buffer и всех краевых случаев REMOVE пока не подтверждены. Защищённый Windows registry автоматически не импортируется.

## Sweep

Добавлен персистентный реестр TARGET по адресу кошелька. Запись содержит публичные address/router/pair_name/last_seen и Mac-снимок пула. Оригинальные `_load`/`_save`: `0x142084980–0x1420867bb`, `0x142086ef0–0x1420886a2`; запись временного JSON с replace.

Sweep повторно ищет маршрут зарегистрированного TARGET. При однозначном ready-результате использует его; иначе ищет ready по сохранённым router/pair и максимальной ликвидности. После TARGET обрабатывает базы, группируя alias по адресу. Восстановленный ключ сортировки — `('WBNB' in aliases, aliases[0].casefold())`, `0x1420a0560–0x1420a0943`: WBNB последним.

Ошибки предварительного balance/route/quote учитываются отдельно, обработка других токенов продолжается. После durable begin ошибка исполнения сохраняет блокировку неоднозначной операции. Итог содержит проданные, пропущенные, ошибки, остатки и балансы, которые не удалось прочитать. Ошибка чтения не означает ноль.

Старый глобальный known_pools нельзя достоверно распределить по кошелькам. При наличии нового реестра неподтверждённые старые TARGET не продаются автоматически: они включаются в skipped и проверку остатков. Их нужно выбрать и зарегистрировать для нужного кошелька. Сохранённые позиции этого кошелька учитываются отдельно. STOP между операциями может завершить Sweep до итоговой сверки. Все ветви частичных Windows-ошибок, лимиты повторов и пыль требуют дальнейшего сопоставления.

## Восстановление и настройки

Подтверждён защищённый Windows JSON-envelope: format `NRNF-DPAPI`, version, base64 payload. `_atomic_write_bytes` `0x141dcbb00–0x141dcd548`: временный файл, write, flush/fsync, chmod 0600, replace и cleanup. Это не доказывает наличие либо семантику Windows-журнала транзакций.

Добавлены четыре проверки настоящего завершения дочернего **Mac Python-процесса** через `os._exit`: после намерения, имитации отправки, receipt и учёта позиции. После перезапуска незавершённая операция блокирует новый begin. Подпись использует одноразовый ключ без средств, отправка подставная. Отключение питания, reorg, финальность и Windows crash/restart не проверялись.

Mac сохраняет router/pair и AMOUNT отдельно по `ROUTER:pair`, восстанавливает их в DEMO; старый формат preferences version 1 продолжает читаться. Добавлен чистый преобразователь `preferences.from_windows_ui` публичного UI JSON: trade, pair_amounts и legacy amount_wbnb. Он не импортирует RPC/ключи, не расшифровывает DPAPI и пока не представлен кнопкой импорта. Все изменения пользовательских файлов требуют отдельного явного запуска импорта. Геометрия окна и все версии Windows-миграций не перенесены. Значения .02/3/2/150 подтверждены константами UI; весь набор Windows defaults ещё не объявлен совпадающим.
