## Метод и воспроизводимость

Разобраны потоки констант `autopair`, `dynamic_pairs`, `wallet_sweep`, `runtime_config`, `gui`. Для восьми функций сопоставлены RIP-ссылки на таблицы констант, дизассемблирование Capstone и декомпиляция radare2/r2ghidra. Декомпилятор теряет часть аргументов: спорные вызовы проверялись по регистрам в ассемблере. Это реконструкция поведения, не восстановленные Python-исходники.

`RECOVERY_EVIDENCE.json` содержит SHA256 релиза, адреса таблиц, выбранные публичные константы и хеши диапазонов кода. Воспроизведение без запуска EXE:

```bash
python -m tools.recovery_native /absolute/path/to/original.exe --output /tmp/recovery-evidence.json
# Дополнительно, в отдельном окружении с Capstone:
python -m tools.recovery_native /absolute/path/to/original.exe --output /tmp/recovery-evidence.json --disassembly /tmp/recovery-asm
```

Инструмент отказывается обрабатывать другой SHA256. Полные декомпиляции и EXE в репозиторий не добавляются.

## Исправления Mac и независимые проверки

1. **STOP при Converter.** Повторная проверка после configure и чтения SELL ALL balance, до begin/sign/broadcast. Раньше STOP, пришедший во время RPC-подготовки, пропускался.
2. **STOP при Sweep.** Повторная проверка после проверки/котирования target и после поиска base-маршрута. Если транзакция уже отправлена, её учёт завершается; повторная отправка не разрешается.
3. **Непроданная позиция после Sweep.** Пропуск target из-за отсутствия маршрута сохраняет entry для TP/SL. Раньше entry безусловно становился None при сохранённой позиции.
4. **Sweep после перезапуска.** Пулы сохранённых позиций текущего кошелька включаются в список обработки даже при отсутствии записи known_pools; адреса пулов дедуплицируются.
5. **Позиция другого пула.** START/BUY в LIVE не допускаются, если у того же кошелька есть сохранённая позиция другого пула. Можно выбрать её пул либо явно выполнить SELL WALLET → BNB. Перезапуск больше не скрывает её от этого ограничения.
6. **ADD BASE.** Проверка round trip котирует полный путь через quote_route. Раньше промежуточные шаги котировались отдельно, хотя исполнение конвертера использует цельный путь. Порог Mac 0.01 WBNB/10% остаётся собственным ограничением, не объявлен восстановленным Windows-порогом.
7. **Настройки.** Сохранение после остановки worker исключает гонку с журналом. Разрешён только явный список числовых полей; NaN/Infinity, неизвестная версия, неверные диапазоны отклоняются. RPC, ключи и режим LIVE не сериализуются в UI preferences. Ошибка записи восстанавливает прежнее состояние памяти. После старта выбран DEMO, торговля не возобновляется автоматически.

Эти исправления проверяют собственные инварианты Mac. Они не доказывают такое же восстановление после crash у Windows.

## Проверки и пределы

- 117 offline-тестов прошли; добавлено 16 сценариев, включая параметризованные. Осталось прежнее предупреждение websockets.legacy.
- Source GUI smoke: exit 0. Дополнительно два последовательных Window с временным Store: параметры восстановлены, DEMO сохранён, RPC/Keychain не использовались.

- Реальные транзакции, запуск Windows и сравнение runtime не выполнялись.

P12 и P18 теперь **PARTIAL / CONFIRMED DIFFERENCES**, а не полностью неизвестные области. P13 также сужен до поведения original crash/restart и оставшихся ветвей Sweep; проверка Mac не закрывает этот пробел. P14 остаётся **NOT TESTED**, поскольку пользователь исключил запуск оригинала.

Их нельзя честно закрыть наличием декомпиляции. Полное совпадение, устойчивость RPC, токены с tax/blacklist и готовность LIVE не подтверждены.
