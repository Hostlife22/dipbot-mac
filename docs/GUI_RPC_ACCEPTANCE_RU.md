# Проверка AutoPair и окна macOS — 24 сентября 2026

Проверка выполняется с временным state.json, без пользовательского кошелька и
Keychain. Сетевой транспорт ограничен `eth_chainId`, `eth_getBlockByNumber`,
`eth_getCode`, `eth_call`. Подписание и отправка транзакций не выполнялись.

## Реальная BSC

`tools.read_only_probe` успешно проверил USDT/WBNB через
`bsc-rpc.publicnode.com`: 5 кандидатов, котировки покупки и продажи V2/V3,
распознавание адресов пулов и базового токена. Все 15 чтений метаданных через
Multicall совпали с отдельными запросами на одном блоке (123789290).
Численные результаты сохранены в `READ_ONLY_ACCEPTANCE.json`.

Основной endpoint `bsc-dataseed-public.bnbchain.org` отказал в соединении.
Альтернативы `bsc-rpc.publicnode.com` и `bsc-dataseed.binance.org` ответили
chainId 56. Это наблюдение на момент проверки, а не гарантия доступности.

## Окно macOS

`tools.gui_acceptance` открывает настоящее окно Qt Cocoa и использует QTest
для ввода и нажатий, с действующим Worker/QThread и очередью сигналов.
Это автоматизированный GUI-прогон, не ручная проверка человеком.

- Через реальный RPC: ввод USDT, поиск V2/WBNB, выбор, чтение цены; затем
  ввод адреса найденного пула и повторный поиск.
- При контролируемой задержке поиска: несколько смен ввода; запоздалый ответ
  не восстанавливает прежний выбор и не разрешает START.
- Искусственный PENDING оставляет возможность повторного поиска.
- Реальный отказ HTTP-соединения с localhost вызывает сообщение об ошибке;
  после возвращения доступного BSC RPC повторный поиск успешен.
- Для искусственной базы выполнены настоящие команды CHECK POOL, ADD BASE,
  REMOVE. Сеть/конвертер этой части подменены: это не проверка нового токена
  на реальной BSC.
- Закрытие окна и новый процесс проверяют router, профиль, сумму 1.25 и
  необходимость новой проверки пула. После REMOVE профиль отсутствует
  при повторном открытии, выбор переключается на WBNB.

Модальные предупреждения перехватываются и проверяются по тексту, чтобы
прогон не ждал человека. Результаты — `GUI_ACCEPTANCE.json`.

## Повторение

```bash
uv run --frozen python -m tools.read_only_probe \
  --endpoint https://bsc-rpc.publicnode.com --output /tmp/dipbot-readonly-check.json
uv run --frozen python -m tools.gui_acceptance --output /tmp/dipbot-gui-check.json
```

Для второго запуска нужна графическая сессия macOS. PNG сохраняется рядом
с JSON. Реальные сделки, token tax и runtime-совпадение с Windows не проверялись.
