# Видимая проверка PAPER: 0x9d095e…87777

Токен: `0x9d095e24b2ae45913b5efbb6eacf48fb8e287777`.
Пул PancakeSwap V2: `0xd0eD8aE279F6134D400eB76DE0F6aDbCD9973c29`, пара WBNB.
Дата: 2026-09-24. Запущено видимое Cocoa-окно из текущего исходного кода,
с отдельным временным Store. LIVE и доступ к кошельку запрещены стендом;
RPC разрешает только чтение. Сохранённые настройки пользователя не изменяются.

## Сценарий

1. Подключение к публичному RPC, AutoPair по адресу токена, проверка пула.
2. BUY NOW на 0,00003 WBNB в PAPER; отдельная ручная продажа спустя 12 секунд.
3. Пять минут автоматической стратегии на реальных текущих ценах: DIP 3%,
   TP 2%, SL 2%, slippage 3%. Цены не подменяются, записанный рынок не используется.
4. STOP и проверка отсутствия остаточной виртуальной позиции.

Статус, цена, последняя точка графика, TARGET quantity и уровни проверяются
по событиям Worker. Расчёт цены дополнительно независимо сверен с резервами
на одном блоке, а доступность buy/sell проверена read-only котировками роутера.

## Что означает PAPER

Цена выражена в WBNB за один TARGET, а не в USD. Ручная покупка через BUY NOW
не доказывает, что автоматический DIP сработал.

PAPER рассчитывает количество как `amount / (price × 1,03)`, а продажу как
`quantity × price × 0,97`. Поэтому при неизменной цене круговая сделка убыточна
из-за моделируемого slippage. Это не точное воспроизведение исполнения роутера:
газ и token tax не учитываются, slippage используется как фиксированное
ухудшение цены. Read-only котировка также не доказывает, что токен можно
продать реальной транзакцией при любых ограничениях контракта.

Первый запуск вспомогательного стенда ошибочно вызвал загрузку RPC из Keychain;
доступ был заблокирован, рынок не тестировался. Исправлено подключение через
кнопку «Подключить», проверка выполнена заново с новым временным хранилищем.

## Отображение USD

По просьбе пользователя цена, база DIP, ось графика, уровни и подсказка
переведены в USD. Пример на этом токене — около $0.000251 за TARGET.
Курс базового актива берётся асинхронно из публичного DEX Screener API,
обновляется раз в 30 секунд; после 90 секунд без успешного получения
интерфейс возвращается к явно подписанной исходной валюте. API не даёт
времени самой котировки: указан возраст получения ответа, USD обозначен
ориентировочным. Все точки графика пересчитываются по текущему курсу;
это не исторический валютный график. DEMO/REPLAY остаются в исходных единицах.

Стратегия, пороги, TARGET quantity и AMOUNT не пересчитываются в USD.
372 offline-теста прошли, включая независимую проверку формулы пересчёта,
выбор сети/адреса валюты, истечение курса и сброс при смене режима.
После финального уточнения подсказки и отсутствующей базы — 11 профильных
тестов прошли. Повторный видимый PAPER: 60 секунд, 765 проверок отображения,
0 расхождений, ручные BUY/SELL и STOP прошли, 0 реальных транзакций.

[Окно USD](gmgn-paper/usd-automatic_end.png),
[отчёт USD](gmgn-paper/usd-report.json).
Новая сборка: `dist/usd/DipBot Mac.app`.

Источник курса: [официальный API DEX Screener](https://docs.dexscreener.com/api/reference).
