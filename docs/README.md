## Исторические материалы

Промежуточные отчёты, скриншоты, выгрузки и анализаторы удалены из рабочего дерева. Они доступны в [последнем полном снимке до очистки](https://github.com/Hostlife22/dipbot-mac/tree/89e3a4f). Это исторические свидетельства, не текущие инструкции или открытый план работ.

Посмотреть отдельный файл без восстановления всего архива:

```bash
git show 89e3a4f:docs/VALIDATION_RU.md
```

Новые отчёты прогонов сохраняйте в `.local-artifacts/` или `/tmp`. В Git оставляйте актуальные руководства и необходимые воспроизводимые тестовые fixtures; не добавляйте очередной отчёт вместо обновления текущего статуса.
