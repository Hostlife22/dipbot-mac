# Обновление интерфейса macOS

## Что изменено

- Единая тёмная палитра, спокойные поверхности, одинаковые поля и отступы.
- Компактная шапка и выровненные вкладки; карточки показателей с читаемой иерархией.
- Контрастные focus/hover/pressed/disabled-состояния; LIVE выделяется отдельным
  цветом и текстом. Состояние RUNNING/LOCKED также имеет текст, не только цвет.
- Поля адресов занимают всю ширину блока; числовые настройки выровнены вправо.
- График оформлен отдельной карточкой; сетка соответствует ценовым подписям,
  уровни ENTRY/TP/SL/DIP сохранили названия и различимые цвета.
- ACTIVITY LOG сворачивается; при ошибке автоматически раскрывается.
  Кнопка STOP остаётся вне прокручиваемой области и доступна на всех вкладках.
- Таблица: чередование строк, без лишней сетки и номеров строк, один выбранный актив.
- Справка разбита на разделы; исправлены устаревшие утверждения про 10 секунд,
  синусоидальный DEMO и расчёт TP. Торговый алгоритм не изменялся.
- Стрелки списков — локальный SVG, входящий в сборку; сетевых шрифтов и картинок нет.

## Проверки

Полный offline-набор после переработки: **368 passed**.
Сборка PyInstaller, проверка codesign --verify --deep --strict и smoke-test прошли.
Функциональная проверка собранного GUI использует read-only PAPER и явно
помеченный повтор записанных цен для BUY/TP/SL; её результат приведён ниже.

Воспроизвести offline-обзор:

```sh
uv run --frozen python -m tools.design_review --output /tmp/dipbot-design-review
```

Вспомогательный стенд использует QApplication.setActiveWindow для проверки
клавиатуры на Mac; Qt выдаёт deprecation warning. Это не код обычного приложения.
