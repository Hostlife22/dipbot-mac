# PAPER-проверка мем-токенов BSC

Проверены адреса FLOKI, BabyDoge, CHEEMS, short и trust. Это техническая
выборка, не рекомендации по покупке. Кошелёк и Keychain заблокированы,
RPC разрешает только чтение; реальных транзакций нет.

## Сценарий

`tools/meme_paper_probe.py` использует Chain, AutoPair resolver и настоящий
Worker/QThread в PAPER. У каждого запуска временное хранилище.

- Ввод адреса токена, поиск PancakeSwap V2/V3 с базой WBNB.
- Каноническая проверка лучшего доступного пула каждого router, распознавание
  его адреса обратно в токен; положительная цена и котировки в обе стороны.
- При AMBIGUOUS пул выбирается явно, V2 первым; автоматический выбор не имитируется.
- Наблюдение рынка: DIP 3%, TP/SL 2%, интервал 0.1 с, порог разрыва 0.55 с,
  виртуальная сумма 0.00003 WBNB. STOP и завершение рабочего потока.
- Отдельно, **на искусственных ценах**, выполнены BUY → TAKE_PROFIT и
  BUY → STOP_LOSS с масштабом первой реальной цены каждого токена.
  Эти сценарии не считаются рыночными сделками.

## Первоначальная нагрузка

Два пересекающихся запуска: три крупных мем-токена и два токена из GMGN,
до пяти одновременно опрашиваемых пулов на PublicNode. Это повышенная нагрузка
относительно обычного приложения с одной выбранной парой.

| Токен | Проверенные router | Наблюдения до STOP/ошибки | Итог |
|---|---|---:|---|
| FLOKI | V2, V3 | 288 | Пауза после HTTPError |
| BabyDoge | V2, V3 | 293 | Пауза после HTTPError |
| CHEEMS | V2, V3 | 294 | Пауза после HTTPError |
| short | V2 | 52 | Пауза после HTTPError |
| trust | V2 | 1226 | Три минуты без ошибки RPC |

HTTP-код в этих первых запусках не записывался: лимит запросов возможен,
но **429 не подтверждён**. Дополненный инструмент сохраняет код HTTP для
будущих ошибок. Повторные проверки выполняются через Binance RPC.

Рыночных BUY/TP/SL в первых запусках не было. Trust показал только одну
уникальную цену: многочисленные успешные чтения не означают активного рынка.
Все десять искусственных сценариев BUY → TP/SL завершились успешно.

Исходные результаты, включая ошибки:
[крупные токены](MEME_PAPER_INITIAL.json), [GMGN](GMGN_PAPER_INITIAL.json).

## Источники адресов

- [FLOKI, документация проекта](https://docs.floki.com/floki-whitepaper-japan/legal-disclaimer/faq).
- [BabyDoge, адрес контракта](https://support.poloniex.com/hc/en-us/articles/12460054696855-New-Listing-Baby-Doge-Coin-BABYDOGE).
- [CHEEMS, BscScan](https://bscscan.com/token/0x0df0587216a4a1bb7d5082fdc491d93d2dd4b413).
- [short, GMGN](https://gmgn.ai/bsc/token/0x7c46508f0937a0c8fb4c34fa20fef70ec9a6bbbb).
- [trust, GMGN](https://gmgn.ai/bsc/token/0x17d64841ef7a22b1999dadfa3e0494ccff5e7777).

Наличие активных PancakeSwap-пар short/trust предварительно проверено через
DexScreener token-pairs API, затем независимо через factory и RPC приложения.
GMGN используется как источник кандидатов; интеграции аккаунта GMGN нет.

## Ограничения

Котировка роутера не исполняет реальный перевод токенов и не доказывает
возможность продажи, отсутствие honeypot, налогов или ограничений контракта.
PAPER не воспроизводит газ, подтверждения и token tax. Проверка не распространяется
на все токены GMGN, другие сети или внутренние рынки launchpad до создания
поддерживаемого пула. GUI на этих токенах отдельно не прогонялся.

## Повторение

```sh
uv run --frozen python -m tools.meme_paper_probe \
  --token short=0x7c46508f0937a0c8fb4c34fa20fef70ec9a6bbbb \
  --endpoint https://bsc-dataseed.binance.org \
  --seconds 180 --output /tmp/meme-paper.json
```

Без `--token` проверяются FLOKI, BabyDoge и CHEEMS одновременно.
Для обычной нагрузки используйте один `--token` на запуск.

## Повтор через Binance RPC

FLOKI, BabyDoge и CHEEMS запускались последовательно; отдельный short частично
пересёкся по времени с FLOKI. Все четыре повтора завершились без HTTP-ошибок.

| Токен | Время | Наблюдения | Медиана / максимум чтения | Сбросы 0.55 с |
|---|---:|---:|---:|---:|
| [short](GMGN_SHORT_RETRY.json) | 90.01 с | 419 | 205.98 / 1628.0 мс | 3 |
| [FLOKI](MEME_FLOKI_RETRY.json) | 60.0 с | 259 | 195.43 / 1306.46 мс | 8 |
| [BabyDoge](MEME_BABYDOGE_RETRY.json) | 60.0 с | 151 | 322.49 / 2362.38 мс | 25 |
| [CHEEMS](MEME_CHEEMS_RETRY.json) | 60.0 с | 203 | 249.03 / 1132.84 мс | 10 |

Рыночных BUY/TP/SL в повторах также не было. Short показал девять разных цен,
но движения не удовлетворили DIP 3%. Повторные искусственные циклы TP/SL прошли.

Итог: поддерживаемые пулы пяти выбранных токенов распознаются, цены и номинальные
котировки читаются, PAPER и STOP работают. Стабильное соблюдение 0.55 с на
публичных RPC **не подтверждено**; при ошибке сеть останавливает наблюдение,
автоперезапуска нет. Исправления основного приложения по этому проходу не вносились.

Дополнительно: 13 offline-тестов PAPER-цикла и RPC-оптимизации прошли.
Полные рыночные циклы и реальные сделки на мем-токенах остаются непроверенными.
