# Общая константа Sweep и путь ошибки REMOVE

Статический проход 2026-09-24, Windows v1.4.14. Оригинал не запускался. Код приложения Mac не менялся.

## Закрыт порог финальной проверки Sweep

Найдена общая таблица Nuitka по адресу `0x1429a02a0`. Инициализатор по `0x140001024` передаёт её загрузчику `0x142925e40` вместе с пустым именем потока. Загрузчик читает PE-ресурс типа 10, ID 3, находит поток по имени и последовательно заполняет восьмибайтовые слоты.

Третий элемент пустого потока — целое **0**. Он соответствует слоту `0x1429a02b0`, загружаемому в RDX по `0x14209e4a2`. Затем `0x14291fc20` сравнивает финальный баланс с этим значением. Операции richcompare 1 и обратная 5 соответствуют Py_LE/Py_GE по локальным заголовкам CPython 3.12.

В исследованной ветви:

| Баланс | Результат |
|---|---|
| Известный `<= 0` | Переход по `0x14209e4bf` пропускает добавление remaining |
| Известный `> 0` | Формируется метка remaining |
| `None` | Численное сравнение пропускается; remaining и ошибка проверки баланса |
| Ошибка сравнения | Отдельный переход по `0x14209e4b6` |

Это порог **финальной классификации**, а не доказательство всех порогов dust, продажи и конвертации. В Mac финальная проверка сохраняет ненулевой остаток; для неотрицательных token balances граница совпадает. Отрицательное значение Python в Mac также сохранится, тогда как эта ветвь оригинала его пропускает; такое значение не является нормальным результатом uint256 balanceOf. Менять защиту Mac не потребовалось.

## Продолжение REMOVE

От точки ошибки `_save` `0x140bc127f` пройдены 476 достижимых инструкций; неразрешённых прямых переходов внутри разрешённой окрестности нет. В этой части не найдено ссылок на имена из таблицы dynamic_pairs, включая `_records`. Ранее определённые вызовы `__exit__` используют уже сохранённый объект, поэтому отсутствие новых ссылок на имя не означает отсутствия операций с объектами.

Дополнительно прослежены конструктор реестра (401 инструкция) и `_save` (783 инструкции после исправления границы INT3; см. [пересчёт](SHUTDOWN_AUDIT_RU.md)). Конструктор содержит ссылки threading/RLock, `_lock`, `_records`, `_load`; сохранение — `_records`, `sorted`, `asdict`, поля версии/типа и `write_protected_json`.

Полный rollback **не доказан**: обход не раскрывает вызываемые функции, динамические побочные эффекты и SEH. Нельзя превращать отсутствие именованного доступа в доказательство отсутствия восстановления. Атомарное поведение Mac сохранено.

## Инициализация Python/Nuitka

Теперь найден реальный загрузчик общей таблицы, а не только предполагаемое расположение слота. Он обращается к FindResourceA/LoadResource/LockResource, содержит восемь вызовов PyDict_New и вызывает декодер объектов `0x142924cd0`, продвигая указатель назначения на 8 байт.

Это дополнительная карта зависимостей инициализации. Ни словари, ни функции, ни получатели в эмуляторе этим проходом не инициализированы; FLOSS заново не запускался и новых строк нет. Оставшиеся tuple/kwargs и граф вызываемых функций по-прежнему требуют разбора.
