# Ограниченная LIVE-проверка BSC — 24 сентября 2026

Пользователь разрешил сделки предоставленным локальным ключом в пределах
доступного баланса. Использованы существенно меньшие суммы: первоначально
0.0001 BNB, для дополнительного сценария — 0.00003 BNB. Секрет не выводился,
не записывался в репозиторий и не добавлялся в Keychain. Журнал исполнения
сохранён отдельно от обычного state.json приложения, вне репозитория.

## Подтверждённые результаты

- Реальные approve точной суммы, BUY и SELL для USDT/WBNB через V2 и V3.
- Запись фактической позиции после receipt и её удаление после SELL.
- Converter BNB → WBNB и обратное преобразование; продажа USDT → BNB.
- Sweep для токена, который одновременно является target и базой каталога.
- Отдельный реальный Sweep target USDC → WBNB → BNB: без пропусков,
  остатков и незавершённых операций; сохранённая позиция очищена.
- Первый RPC не вернул receipt отправленного wrap. Автоматического повтора
  не было; второй RPC подтвердил тот же hash, nonce и поступление WBNB.
  Журнал сверили через reconcile, затем закрыли операцию после проверки баланса.
- ADD/REMOVE профиля USDC по реальным пулам и котировкам в отдельном временном
  хранилище, без транзакций; удаление после перезапуска хранилища подтверждено.
- PAPER: ручные BUY/SELL по реальным ценам, START, пять наблюдений, STOP;
  отказ RPC сохраняет виртуальную позицию и приостанавливает работу,
  после восстановления соединения SELL выполняется.

## Найденная ошибка и исправление

Если target входит в базовый каталог (USDT), Sweep может продать его через
Converter. Ранее эта ветвь не обновляла сохранённую позицию и оставляла токен
в `skipped`, даже когда он уже попадал в `sold` и баланс был нулевым.

Теперь после конвертации читается остаток и обновляются позиции этого
кошелька до закрытия журнала. Нулевой остаток удаляет позицию; частичный
ограничивает учтённую сумму фактическим балансом. Уже нулевой базовый актив
также позволяет очистить старую запись. Ошибка чтения после конвертации
не закрывает журнал операции. Добавлены регрессионные тесты.

Найденная устаревшая тестовая позиция сверена и очищена новым кодом через
read-only RPC. Дополнительных транзакций для этого не потребовалось.

## Границы проверки

Не подтверждены все токены/маршруты, fee-on-transfer, автоматическое
срабатывание DIP/TP/SL на длительном реальном рынке, реальные аварии процесса
во время подписания и полное совпадение с Windows. LIVE-команды проверялись
через Worker/LiveTrader из исходников. Собранное приложение отдельно проходит
проверку запуска и подписи; полная цепочка LIVE через GUI/Keychain не выполнялась.

350 offline-тестов прошли. Сборка x86_64 создана через BUILD_MAC.command;
нативный smoke-test и codesign --verify --deep --strict прошли для итогового приложения.
Индивидуальные hashes, адрес кошелька и локальное состояние не включены
в этот публичный отчёт.
