# DipBot Mac 0.1

Независимый аналог NRNF DipBot для macOS с исходным кодом. Создан по документации и статическому разбору Windows-сборки v1.4.14. Это экспериментальная реализация, а не восстановленный исходный проект автора. Совпадение торговых сигналов с оригиналом не установлено.

## Запуск

Откройте `dist/DipBot Mac.app` или дважды нажмите `START_MAC.command`.
Готовая `.app` в этой папке собрана для **Intel x86_64** на macOS 26.6.2. Apple Silicon нативно требует отдельной сборки в arm64-окружении. Приложение подписано ad-hoc, без Developer ID и нотарификации Apple.

Из терминала:

```bash
cd /Users/admin/Projects/MyProjects/solana/dipbot-mac
uv sync --frozen
uv run --frozen python launcher.py
```

Сначала можно нажать **START BOT** в режиме **DEMO**. Он работает без RPC, кошелька и доступа к сети.

## Режимы

| Режим | Цена | Исполнение |
| --- | --- | --- |
| DEMO | Локальная синусоидальная модель | Виртуальные сделки |
| PAPER | Настоящие резервы V2 / slot0 V3 через BSC RPC | Виртуальные сделки |
| LIVE | Настоящий рынок BSC | Реальные подписанные транзакции |

PAPER учитывает заданное проскальзывание в обе стороны, но не газ, token tax, влияние размера заявки или фактический выход router. PAPER P&L не является прогнозом результата LIVE.

## Настройка BSC и LIVE

1. Во вкладке **RPC и кошелёк** укажите BSC HTTPS RPC, нажмите **Подключить**. Проверяется chainId 56 и свежесть блока.
2. Для просмотра балансов достаточно публичного адреса. Для LIVE введите private key **отдельного** кошелька и нажмите **VERIFY WALLET AND SAVE · Keychain**. Поле очищается, ключ сохраняется только в macOS Keychain.
3. Укажите GAS GWEI. Верхняя граница расходов газа — 0.005 BNB **на одну** транзакцию, включая approve. Несколько шагов суммируются.
4. Во вкладке **Торговля** задайте TOKEN ADDRESS. Выберите PAIR и ROUTER, нажмите **AutoPair**. `ALL` ищет среди всех встроенных и пользовательских баз, что может быть медленно.
5. Если найден один ликвидный пул, он выбирается автоматически. Если несколько — выберите точный маршрут и нажмите **Выбрать**. Если адрес пула уже известен, используйте POOL ADDRESS и **CHECK POOL**.
6. **AMOUNT задаётся в базовом ERC-20 активе выбранного пула**, а не всегда в BNB. Для пары WBNB сначала оберните BNB через **BUY BASE**. Боту также нужен отдельный остаток нативного BNB для газа.
7. Настройте DIP, TP, STOP LOSS, SLIPPAGE и DYNAMIC. Выберите LIVE. START, ручной BUY, Converter и Sweep показывают подтверждение с адресами перед реальным исполнением.

Ни одного реального approve, swap, wrap или перевода при разработке не выполнялось. Подписание и отправка проверены только локальными заглушками; перед использованием значимых средств необходима отдельно разрешённая проверка выделенным тестовым кошельком. V3 не предназначен для fee-on-transfer токенов.

## Торговые правила этой реализации

- Пока позиции нет, база — максимум наблюдаемой цены. BUY происходит при падении от базы на DIP процентов.
- После разрыва котировок более 10 секунд база входа сбрасывается. При открытой позиции проверки TP/SL продолжаются после возобновления чтения.
- В LIVE цена входа рассчитывается из суммы базы и реально полученного количества target после подтверждения BUY.
- TP и STOP LOSS сравнивают цену пула с ценой входа. После TP бот продолжает работу; после STOP LOSS останавливается.
- BUY-допуск: `SLIPPAGE − DYNAMIC / 100`, значение не может быть отрицательным. Допуск применяется к `getAmountsOut` / QuoterV2. После approve берётся новая котировка, но прежний minOut не ослабляется.
- SELL POSITION продаёт только учтённую позицию бота, ограниченную фактическим балансом. Ранее имевшиеся токены не включаются автоматически.
- STOP ждёт текущую отправку и receipt, после чего закрывает учтённую позицию. При неизвестном результате отправки вместо новой сделки требуется сверка.
- RPC-ошибка при работе останавливает автоматический цикл; открытая позиция может остаться. После восстановления RPC доступны SELL POSITION и STOP.

Правило максимума цены, точный порядок TP и сброса базы — явно выбранная реконструкция. Найденное в EXE правило `2 down moves` не реализовано: его точное условие не восстановлено. Пауза чтений по умолчанию 1 секунда **после** завершения RPC-запросов; настраивается от 0.1 секунды. Скорость оригинала 100/103 мс не воспроизведена и не обещается.

## Converter, профили и Sweep

- Встроены 42 публичных адреса из EXE. Их присутствие в каталоге не подтверждает ликвидность или благонадёжность токена.
- V2/V3 маршруты проверяются по официальной factory, token0/token1, каноническому getPair/getPool и ненулевой ликвидности.
- **ADD BASE** добавляет сторону выбранного пула после котировки WBNB → base → WBNB на 0.01 WBNB; допустимая потеря котировки до 10%. Проверка не выявляет все ограничения продажи, налоги, blacklist или honeypot.
- **REMOVE** удаляет только пользовательский профиль и проверяет отсутствие остатков базы и известных target на указанном публичном кошельке.
- **BUY BASE** конвертирует заданное количество BNB в базу; **SELL ALL BASE → BNB** продаёт весь её баланс. Converter выбирает из прямых и двухшаговых маршрутов через USDT / ETH по котируемому выходу, без оптимизации газа.
- Каждый шаг конвертации — отдельная транзакция. При ошибке предыдущие шаги уже могли исполниться; промежуточные токены остаются в кошельке. Общий допуск делится между шагами, но не ограничивает изменение цены между отдельными транзакциями.
- **SELL WALLET → BNB** сначала продаёт target, зарегистрированные при выборе пула, затем базовые активы каталога и этих пулов. Нативный BNB не продаётся. Неизвестные ERC-20 не перечисляются автоматически.
- При отсутствии маршрута база пропускается с записью в журнал. Неоднозначная отправка, revert или ошибка после начала операции останавливает Sweep для сверки. Это строже поведения оригинала.
- Балансы читаются последовательно; Multicall и зелёная сетка оригинала не воспроизведены. Ненулевые балансы выделяются зелёным в таблице.

## Хранение и восстановление

- Ключ и, по желанию, RPC: **macOS Keychain**, сервис `DipBotMac`, записи `wallet` и `rpc`. Нет fallback на открытый текст.
- Публичные маршруты, адрес кошелька, позиции и журнал: `~/Library/Application Support/DipBotMac/state.json`, права файла 0600. Ключи, RPC и лицензия туда не записываются.
- Перед отправкой на диск атомарно записывается hash подписанной транзакции. После потери ответа RPC повторная отправка автоматически не выполняется.
- При аварийном закрытии незавершённая операция блокирует LIVE. Подключите тот же кошелёк/RPC, нажмите **Проверить receipts**, обновите балансы. После ручной сверки можно снять блокировку.
- Снятие блокировки сбрасывает кэш позиций этого кошелька. Токены остаются на нём; используйте зарегистрированные маршруты и Sweep для выхода.
- Если receipt не найден, блокировка сохраняется. Для dropped/непереданной транзакции автоматической отмены или замены nonce в этой версии нет; необходим отдельный разбор hash и nonce. Не удаляйте журнал наугад.
- Успех означает `receipt.status == 1`; ожидание дополнительной финальности и восстановление после реорганизации цепочки не реализованы.
- Приложение предотвращает запуск второго локального экземпляра. Не используйте тот же торговый кошелёк параллельно в другом боте: это нарушит учёт балансов и nonce.

## Проверки и сборка

```bash
uv sync --frozen --group dev
uv run --frozen pytest -q
QT_QPA_PLATFORM=offscreen uv run --frozen python launcher.py --smoke-test
./BUILD_MAC.command
```

Для нативной Apple Silicon сборки выполните эти команды в новом arm64-окружении Python 3.12/3.13. Библиотеки Windows не используются. Сборка на других версиях macOS/архитектурах пока не проверена.

Результаты: [VALIDATION_RU.md](docs/VALIDATION_RU.md). Разбор оригинала: [REVERSE_ENGINEERING_RU.md](docs/REVERSE_ENGINEERING_RU.md). Публичные извлечённые данные: [REVERSE_EVIDENCE.json](docs/REVERSE_EVIDENCE.json).

## Структура

| Файл | Назначение |
| --- | --- |
| `dipbot/app.py` | Интерфейс PySide6 |
| `dipbot/worker.py` | Последовательный цикл, команды, восстановление позиции |
| `dipbot/chain.py` | BSC RPC, ABIs, проверка пулов, цены, котировки |
| `dipbot/trader.py` | Подписание, approve, V2/V3, конвертация, журнал |
| `dipbot/strategy.py` | Реконструированная стратегия и точная арифметика сумм |
| `dipbot/storage.py` | Keychain и атомарное публичное состояние |
| `tools/inspect_release.py` | Воспроизводимый статический анализ EXE без запуска |
