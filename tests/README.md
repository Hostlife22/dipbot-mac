# Тесты

```bash
QT_QPA_PLATFORM=offscreen uv run --frozen pytest -q
```

Папки `domain`, `application`, `market`, `execution`, `persistence`, `ui`,
`research` и `architecture` группируют сценарии по подсистемам.
Смешанные интеграционные сценарии остаются целыми: assertions не удаляются ради классификации.

`support/` содержит общие builders, константы и fixtures. Общие fixtures
`trader` и `window` регистрируются через корневой `conftest.py`.
Тестовые модули не импортируют друг друга; это проверяет архитектурный тест.
Pytest работает в режиме importlib, без добавления каталогов тестов в sys.path.

Основной набор локальный: RPC и отправка подменяются заглушками. Он не доказывает
поведение Windows или прибыльность. Исторические имена native/parity/audit
сохранены там, где они описывают происхождение регрессий.

Сетевые и визуальные прогоны запускаются отдельно через [tools](../tools/README.md).
