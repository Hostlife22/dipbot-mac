# Тесты

```bash
QT_QPA_PLATFORM=offscreen uv run --frozen pytest -q
```

Основной набор — локальные проверки стратегии, UI, RPC-заглушек, исполнения, журналирования, восстановления и учёта. Он не требует реального кошелька и не доказывает поведение Windows или прибыльность.

Файлы с историческими именами `phase3`, `native_followup`, `parity`, `audit` содержат действующие регрессии AutoPair, Sweep, защищённого формата и аварийного восстановления. Не удаляйте их по названию. Некоторые модули используют общие fixtures из соседних тестов.

Удалены только проверки выведенного из проекта декодера Windows EXE. Воспроизводимые fixtures и сравнительные модели сохранены. Сетевые, визуальные и LIVE-проверки запускаются отдельно через [tools](../tools/README.md).
