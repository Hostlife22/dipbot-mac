# Чувствительные данные и сообщения об уязвимостях

DipBot Mac 0.1 — экспериментальная версия. Наличие LIVE-кода не означает проведённый аудит или подтверждённую безопасность работы со средствами. Текущие ограничения перечислены в [руководстве](README_RU.md) и [текущем статусе](docs/CURRENT_STATUS_RU.md).

## Что не публиковать

Private key, seed-фразы, лицензии `.nrnflic`, RPC URL с ключом доступа, дампы Keychain и локальное состояние кошелька нельзя прикладывать к issues, PR или логам CI. Для воспроизведения используйте DEMO, mock-ответы и случайные нефинансируемые тестовые ключи.

`state.json` не содержит private key, но включает адреса, позиции и историю операций. Не прикладывайте его целиком к публичному issue. Сначала подготовьте минимальный обезличенный пример.

## Сообщить об уязвимости

Если в разделе GitHub **Security** доступна кнопка **Report a vulnerability**, используйте приватный отчёт. Иначе свяжитесь с владельцем репозитория через доступный ему приватный канал; не публикуйте детали активной уязвимости вместе с данными реального кошелька.

Укажите версию/commit, macOS и архитектуру, затронутую функцию, ожидаемое и фактическое поведение. Для проблем исполнения полезен минимальный тест с подменой RPC и отправки транзакций.
